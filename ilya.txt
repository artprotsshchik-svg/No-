================================================================================
1. РЕНДЕР, CULLING И FPS
================================================================================

• Rubidium -> [УСТАРЕЛ НА 1.20+]
  - Описание: Классический порт Sodium на Forge 1.16-1.19. На 1.20+ полностью заменен на Embeddium.
  - Альтернатива / Вердикт: Embeddium.
  - Внимание: Нельзя ставить одновременно с Embeddium!

• Embeddium [установлено] -> [МАСТХЭВ]
  - Описание: Главный поддерживаемый порт Fabric-мода Sodium на Forge/NeoForge (развитие Rubidium от embeddedt). Полная переработка рендера чанков через OpenGL 4.3 с максимальной совместимостью с модами.
  - Альтернатива / Вердикт: Эталон для Forge 1.20.1+.

• Embeddium Extras -> [МАСТХЭВ (АДДОН)]
  - Описание: Аддон к Embeddium (аналог Sodium Extra для Forge): добавляет тонкие настройки неба, погоды, тумана, частиц и FPS-счетчик. Полностью совместим с (Sodium) Chloride.
  - Альтернатива / Вердикт: Ставить вместе с Embeddium.

• Emberbium -> [ТЮНИНГ ДЛЯ 1.20.1]
  - Описание: Форк Embeddium от Misanthropy под Forge 1.20.1. Внедряет Radix Sort чанков, оптимизирует Draw Calls для шейдеров Oculus и чинит утечки при смене миров.
  - Альтернатива / Вердикт: Ставится ВМЕСТО Embeddium в тяжелых 1.20.1 сборках с шейдерами.
  - Внимание: Нельзя ставить одновременно с Embeddium, Rubidium или Xenon!

• (Sodium) Chloride -> [АДДОН EMBEDDIUM (EMBEDDIUM++)]
  - Описание: Активный аддон для Embeddium на Forge 1.20.1 (бывший Embeddium++). Добавляет динамическое освещение, куллинг мобов по дистанции, True Darkness, зум и полноэкранный режим без рамок. Совместим с Embeddium Extras!
  - Альтернатива / Вердикт: Ставить вместе с Embeddium как комбайн фич и динамического света.
  - Внимание: Требует Embeddium (не форк, а дополнение). При паре с Embeddium Extras не дублируйте зум/FPS в конфигах.

• Flerovium -> [АДДОН РЕНДЕРА (ПРЕДМЕТЫ/МОБЫ)]
  - Описание: Дополнение к Embeddium / Sodium от MoePus (НЕ форк, а аддон). Ускоряет рендеринг предметов на 50%+, частиц на 50%+ и сущностей на ~30% за счет backface culling, кэширования света и LOD.
  - Альтернатива / Вердикт: Ставить ВМЕСТЕ с Embeddium для сильного буста FPS на складах и в боях.

• ImmediatelyFast -> [МАСТХЭВ]
  - Описание: Оптимизирует немедленный режим рендеринга (Immediate Mode): текст, тултипы, HUD, шрифты, полоски HP мобов, 2D-частицы и GUI.
  - Альтернатива / Вердикт: Мастхэв при использовании JEI / EMI.

• Accelerated Rendering -> [GPU COMPUTE ДЛЯ СУЩНОСТЕЙ]
  - Описание: Клиентское дополнение от Argon4W (совместимо с Embeddium и Oculus). Кэширует вершины и переносит тяжелые матричные трансформации мобов, боссов и block-entities на GPU через Compute Shaders (требует OpenGL 4.6).
  - Альтернатива / Вердикт: Мастхэв для сборок с сотнями мобов и сложными анимированными моделями.
  - Внимание: Требует GPU и драйвер с поддержкой OpenGL 4.6.

• Accelerated Rendering: Turned -> [АЛЬТЕРНАТИВНЫЙ ФОРК]
  - Описание: Тюнингованная сборка Accelerated Rendering с альтернативными весовыми матрицами.
  - Альтернатива / Вердикт: Accelerated Rendering.

• Accelerated Recoiling -> [ТВИК ОТДАЧИ И ВЫЧИСЛЕНИЙ]
  - Описание: Патч анимаций отдачи и вычислений моделей при GPU-рендеринге.
  - Альтернатива / Вердикт: Accelerated Rendering.

• Lagless: FPS Optimizer -> [ПЛАЦЕБО / ОПАСНО]
  - Описание: Любительский мод, заявляющий устранение всех лагов. Грубо урезает дальность прорисовки сущностей и ухудшает освещение без реальной оптимизации кода.
  - Альтернатива / Вердикт: Удалить. Настоящую оптимизацию дают Embeddium, ModernFix и FerriteCore.
  - Внимание: Любительский мод: грубо режет дальность мобов без реальной оптимизации кода.

• More Culling Reforged -> [МАСТХЭВ (ПОРТ MORECULLING)]
  - Описание: Порт Fabric-мода MoreCulling (от MikihinaSann) для Forge 1.20.1. Отсекает невидимые грани ступеней, заборов, люков, рамки на расстоянии и листву. Отлично дополняет Entity Culling.
  - Альтернатива / Вердикт: Лучший мод куллинга граней блоков для Forge 1.20.1.

• Entity Culling -> [МАСТХЭВ (МУЛЬТИ-ЛОАДЕР)]
  - Описание: Оригинальный мультиплатформенный мод от tr7zw (нативно для Forge, NeoForge и Fabric). Асинхронная трассировка лучей скрывает мобов, игроков и сундуки, полностью скрытых за стенами и под землей.
  - Альтернатива / Вердикт: Эталон отсечения невидимых сущностей; идеально работает в паре с More Culling Reforged.

• Brute force Rendering Culling -> [ОПАСНО / НЕСТАБИЛЬНО]
  - Описание: Агрессивно вырезает невидимую геометрию. Нередко приводит к мерцанию блоков, прозрачным чанкам («дырам в мире») и визуальным глитчам с шейдерами.
  - Альтернатива / Вердикт: More Culling Reforged + Entity Culling.
  - Внимание: Агрессивный culling: часто приводит к мерцанию блоков, «дырам» в мире и артефактам шейдеров.

• Brute force Rendering Culling Revived -> [ОПАСНО / НЕСТАБИЛЬНО]
  - Описание: Возрожденный форк Brute Force Culling. Сохраняет проблемы с мельканием блоков и артефактами теней.
  - Альтернатива / Вердикт: Entity Culling.
  - Внимание: Сохраняет баги с мерцанием геометрии и «дырами» в чанках при быстром перемещении.

• (Sodium) Sightline -> [ФОВЕАЛЬНЫЙ КУЛЛИНГ]
  - Описание: Аддон для Sodium/Embeddium, отсекающий чанки строго вне конуса взгляда игрока.
  - Альтернатива / Вердикт: Может вызывать секундные дыры в мире при резких поворотах камеры.

• (Sodium) Streamline -> [ПОТОКОВЫЙ КУЛЛИНГ]
  - Описание: Оптимизация очередей передачи чанков в видеопамять.
  - Альтернатива / Вердикт: Встроенные оптимизации Embeddium.

• (Sodium) Fovea -> [ФОВЕАЛЬНЫЙ РЕНДЕР]
  - Описание: Фовеальный рендеринг: снижает детализацию геометрии на периферии зрения.
  - Альтернатива / Вердикт: Экспериментально, на любителя.

• Cullify -> [ИЗБЫТОЧЕН]
  - Описание: Альтернативный куллер блоков.
  - Альтернатива / Вердикт: More Culling Reforged работает чище и без конфликтов.

• ItemCuller -> [ПОЛЕЗНО ДЛЯ ДРОПА]
  - Описание: Отсекает рендеринг выброшенных на землю предметов, если они перекрыты блоками или находятся вне зоны видимости.
  - Альтернатива / Вердикт: Отлично подходит для моб-ферм и шахт.

• CullLessLeaves Reforged -> [МАСТХЭВ ДЛЯ ЛИСТВЫ (ПОРТ)]
  - Описание: Порт Fabric-мода CullLessLeaves (ccr4ft3r) под Forge 1.20.1. Алгоритмический куллинг скрытых граней листвы внутри крон деревьев — огромный буст FPS в лесах без ухудшения графики.
  - Альтернатива / Вердикт: Эталон оптимизации листвы для Forge 1.20+ (в связке с Embeddium).

• Leaves Culling -> [ДУБЛИКАТ]
  - Описание: Куллинг листвы.
  - Альтернатива / Вердикт: CullLessLeaves Reforged.

• Sodium Leaf Culling (Unofficial) -> [ДУБЛИКАТ]
  - Описание: Неофициальный аддон куллинга листвы.
  - Альтернатива / Вердикт: CullLessLeaves Reforged.

• Legendary Block Entities -> [ПОЛЕЗНЫЙ АНАЛОГ EBE]
  - Описание: Нативная Forge 1.20.1 альтернатива Fabric-моду Enhanced Block Entities: запекает рендеринг сундуков, кроватей, колоколов и шалкеров в быстрые меши чанков без потери анимаций.
  - Альтернатива / Вердикт: Отличная рабочая альтернатива на Forge 1.20.1 наряду с Enhanced Block Entities Reloaded.
  - Внимание: Не ставить одновременно с EBER или FastChest!

• FastChest Revived -> [УПРОЩЕНИЕ СУНДУКОВ]
  - Описание: Убирает динамическую анимацию открывания крышки сундуков, делая их статичными блоками.
  - Альтернатива / Вердикт: Enhanced Block Entities Reloaded (сохраняет красивый визуал).
  - Внимание: Заменяет анимированные сундуки статичными. Несовместим с Enhanced Block Entities и отключает анимацию.

• Optimized Block Entities (OBE) -> [УСТАРЕЛ]
  - Описание: Оптимизирует рендер сундуков и табличек за счет отключения анимаций на расстоянии.
  - Альтернатива / Вердикт: Enhanced Block Entities Reloaded.

• Enhanced Block Entities Reloaded -> [МАСТХЭВ (ПОРТ EBE)]
  - Описание: Современный порт Fabric-мода Enhanced Block Entities (Mat0u5_). Превращает блочные сущности (сундуки, колокола, печи, таблички) в запеченные меши чанков, в разы поднимая FPS на складах.
  - Альтернатива / Вердикт: Лучший выбор для баз и хранилищ (альтернатива на 1.20.1 — Legendary Block Entities).

• Enhanced Block Entities Reforged (Unofficial) -> [УСТАРЕВШИЙ ПОРТ (1.18-1.19)]
  - Описание: Ранний неофициальный порт Fabric-мода EBE от ccr4ft3r, основные релизы которого выходили под Forge 1.18.2 и 1.19.2.
  - Альтернатива / Вердикт: На 1.20.1 используйте Enhanced Block Entities Reloaded или Legendary Block Entities.
  - Внимание: Не смешивайте с EBER или Legendary Block Entities!

• HyperFPS -> [ПЛАЦЕБО]
  - Описание: Псевдо-оптимизатор с сомнительным кодом. Часто ломает дальность прорисовки.
  - Альтернатива / Вердикт: Embeddium + ModernFix.
  - Внимание: Псевдо-оптимизатор: может вызывать сбои дальности рендера.

• Stable FPS -> [ПЛАЦЕБО]
  - Описание: Меняет пару переменных в конфиге без реальной пользы.
  - Альтернатива / Вердикт: FramePacer (для стабильности фреймтайма).
  - Внимание: Меняет пару переменных в конфиге без реальной пользы.

• Tritium -> [КОМБАЙН ОПТИМИЗАЦИЙ]
  - Описание: Универсальный комбайн оптимизаций для Forge (НЕ форк Sodium): включает быструю смену языка, куллинг листвы, оптимизацию сундуков, Dynamic FPS и фиксы тех-модов.
  - Альтернатива / Вердикт: Пересекается по функциям с EBER, CullLessLeaves и Embeddium Extras — выбирайте либо его, либо набор специализированных лидеров.
  - Внимание: Возможны перекрытия с EBER и модами на листву.

• XFermium -> [УСТАРЕЛ / ЗАБРОШЕН]
  - Описание: Экспериментальный форк рендера.
  - Альтернатива / Вердикт: Embeddium.

• Nebula Mod -> [ОПТИМИЗАЦИЯ НЕБА И ТУМАНА]
  - Описание: Оптимизирует рендеринг небесной сферы, звезд и градиентов горизонта.
  - Альтернатива / Вердикт: Embeddium Extras.

• Optimized Fullbright -> [ЯРКОСТЬ БЕЗ ОВЕРХЕДА]
  - Описание: Включает максимальную яркость мира без постоянного пересчета световых карт шейдеров.
  - Альтернатива / Вердикт: Embeddium Extras (ползунок Brightness).

• SkullSkinless -> [ПОЛЕЗНО ДЛЯ ГОЛОВ]
  - Описание: Оптимизирует рендеринг декоративных голов игроков, избавляя от повторной загрузки скинов из сети при каждом кадре.
  - Альтернатива / Вердикт: Идеально для серверов с магазинами и декором.

• DynamicRenderDistance -> [ДИНАМИЧЕСКАЯ ДАЛЬНОСТЬ]
  - Описание: Автоматически снижает дистанцию прорисовки при падении FPS и восстанавливает при нормализации.
  - Альтернатива / Вердикт: Ставить строго один из двух с [DRD]! На серверах лучше ServerCore.
  - Внимание: Дубликат [DRD] Dynamic Render Distance: используйте строго один из них!

• [DRD] Dynamic Render Distance -> [ДИНАМИЧЕСКАЯ ДАЛЬНОСТЬ]
  - Описание: Альтернативный мод динамической дальности прорисовки.
  - Альтернатива / Вердикт: Нужен только один из двух: либо DRD, либо DynamicRenderDistance.
  - Внимание: Дубликат DynamicRenderDistance: используйте строго один из них!

• Lite FPS -> [ПЛАЦЕБО]
  - Описание: Упрощенный твик конфигов, не дающий реального прироста производительности.
  - Альтернатива / Вердикт: Embeddium.
  - Внимание: Упрощенный твик конфигов, не дающий реального прироста.

• Vectors -> [ВЕКТОРНАЯ МАТЕМАТИКА]
  - Описание: Оптимизация математических векторных вычислений в геометрии рендера.
  - Альтернатива / Вердикт: ModernFix (содержит быстрые векторы).

• Kexosyn (Forge) -> [ПАТЧИНГ ВЫЗОВОВ OPENGL]
  - Описание: Экспериментальный твик вызовов OpenGL на Forge.
  - Альтернатива / Вердикт: Embeddium.

• SmartCull+ -> [ИЗБЫТОЧЕН]
  - Описание: Модуль отсечения невидимых полигонов.
  - Альтернатива / Вердикт: More Culling Reforged.

• Fermium -> [УСТАРЕЛ]
  - Описание: Старый форк рендера.
  - Альтернатива / Вердикт: Embeddium.

• VoidEngine -> [ЭКСПЕРИМЕНТАЛЬНЫЙ ДВИЖОК]
  - Описание: Попытка оптимизации конвейера рендера.
  - Альтернатива / Вердикт: Embeddium.

• Prismanium -> [ФОРК EMBEDDIUM (DYNAMIC LIGHTS)]
  - Описание: Активный форк стека Sodium/Embeddium под Forge 1.20.1 со встроенным динамическим освещением, улучшенной совместимостью с Oculus и оптимизацией рендера оружейных модов (TACZ).
  - Альтернатива / Вердикт: Альтернатива Embeddium. Не ставить одновременно с Embeddium!
  - Внимание: Является заменой Embeddium — нельзя ставить вместе с Embeddium!

• CLab -> [ЭКСПЕРИМЕНТАЛЬНЫЕ ТВИКИ GL]
  - Описание: Экспериментальный микро-патч OpenGL.
  - Альтернатива / Вердикт: Embeddium.

• Carbons -> [УСТАРЕЛ]
  - Описание: Старый форк графических оптимизаций.
  - Альтернатива / Вердикт: Embeddium.

• ChaosAPI -> [БИБЛИОТЕКА]
  - Описание: Вспомогательная библиотека для некоторых оптимизаторов рендера.
  - Альтернатива / Вердикт: Ставить только если требует зависимость.

• ForceGL2.0-Remapped -> [ОПАСНО / ДРЕВНИЙ OPENGL]
  - Описание: Пытается принудительно заставить игру работать на древнем OpenGL 2.0. Ломает современные шейдеры, текстуры и Embeddium.
  - Альтернатива / Вердикт: НЕ СТАВИТЬ на версиях 1.17+! Minecraft 1.17+ требует OpenGL 3.2+, а Embeddium — 4.3+.
  - Внимание: Форсирует устаревший OpenGL 2.0. Вызывает немедленный краш с Embeddium/Oculus и графические артефакты на современных GPU.

• JEM Adaptive Culling -> [АДАПТИВНЫЙ КУЛЛИНГ]
  - Описание: Адаптивный куллинг для моделей Custom Entity Models (CEM).
  - Альтернатива / Вердикт: Entity Culling.

• LCull -> [ИЗБЫТОЧЕН]
  - Описание: Легкий куллер сущностей.
  - Альтернатива / Вердикт: Entity Culling.

• Raffman's Optimiser -> [ЛЮБИТЕЛЬСКИЙ / НЕСТАБИЛЬНО]
  - Описание: Сборник агрессивных твиков рендера.
  - Альтернатива / Вердикт: Embeddium + ImmediatelyFast.
  - Внимание: Сборник агрессивных твиков с риском графических глитчей.

• Maple Mesh Render -> [ЭКСПЕРИМЕНТАЛЬНЫЙ МЕШЕР]
  - Описание: Экспериментальная переработка построения мешей чанков.
  - Альтернатива / Вердикт: Embeddium.

• Ravicon -> [ОПТИМИЗАЦИЯ ИКОНОК]
  - Описание: Оптимизация кеширования и рендеринга иконок предметов в инвентаре.
  - Альтернатива / Вердикт: ImmediatelyFast.

• Alloyium -> [GPU-АДДОН К EMBEDDIUM]
  - Описание: НЕ форк, а мощное клиентское дополнение к Embeddium от MisoPy (Forge 1.20.1)! Использует GPU Compute Shaders и Indirect MultiDraw (идея как в Nvidium, но без Mesh Shaders) — ускоряет рендер чанков на любых видеокартах: NVIDIA, AMD и Intel.
  - Альтернатива / Вердикт: Лучшая универсальная альтернатива Nvidium для Forge поверх Embeddium!

• VulkanMod -> [ТОЛЬКО ЧИСТЫЙ FABRIC (НЕ ДЛЯ FORGE)]
  - Описание: Полная замена OpenGL-движка Minecraft на современный Vulkan API для чистого Fabric. Дает рекордный FPS на слабых CPU/GPU, но полностью несовместим с Forge, Sinytra Connector, Embeddium, Nvidium и шейдерами Iris/Oculus.
  - Альтернатива / Вердикт: На Forge используйте Embeddium + Alloyium (или Nvidium через Sinytra).
  - Внимание: Категорически несовместим с Forge, Sinytra Connector, Embeddium и шейдерами!

• Sodium -> [ОРИГИНАЛ FABRIC (НА FORGE — EMBEDDIUM)]

  - Альтернатива / Вердикт: Используйте нативный Embeddium (и добавьте алиас embeddium -> sodium в Sinytra для аддонов).
  - Внимание: Не ставьте Fabric-версию Sodium на Forge — она крашнет игру! Ставьте Embeddium.

• Iris Shaders -> [ОРИГИНАЛ FABRIC (НА FORGE — OCULUS)]
  - Описание: Оригинальный шейдерный движок для Fabric/Sodium. Для Forge 1.20.1 его официальным портом является Oculus (или Emberlens).
  - Альтернатива / Вердикт: Oculus (или форк Emberlens с улучшенной поддержкой Create на 1.20.1).
  - Внимание: Не ставьте Fabric-версию Iris поверх Sinytra на 1.20.1 — используйте Oculus.

• Exordium -> [КОНФЛИКТ МИКСИНОВ С SINYTRA]
  - Описание: Fabric-мод снижения FPS отрисовки GUI/хотбара для разгрузки видеокарты. Через Sinytra Connector на Forge падает с ошибкой InvalidInjectionException из-за конфликта миксинов.
  - Альтернатива / Вердикт: ImmediatelyFast (нативно для Forge, ускоряет весь GUI и HUD без крашей).
  - Внимание: Падает при запуске через Sinytra Connector!

• Thulium -> [ОПТИМИЗАЦИЯ GC И ЗВУКА]

  - Описание: Дополнительный модуль интеграции для Sinytra Connector (REI/EMI мосты, поддержка ресурспаков и библиотек Fabric).
  - Альтернатива / Вердикт: Полезно при запуске нескольких Fabric-модов на Forge.

• Indium -> [НЕ НУЖЕН НА FORGE (EMBEDDIUM НАТИВЕН)]
  - Описание: Прослойка Fabric Rendering API для Sodium. На Forge с Embeddium и Forgified Fabric API полностью избыточен и может вызывать краши.
  - Альтернатива / Вердикт: Удалить — Embeddium нативно поддерживает нужные интерфейсы рендеринга.
  - Внимание: Не устанавливайте Indium через Sinytra Connector с Embeddium.

ПРАВИЛА НЕСОВМЕСТИМОСТИ:
================================================================================
1. Конфликт движков рендера чанков (Форки Sodium) (Рендер, culling и FPS):
   - Конфликтующие моды: Embeddium, Rubidium, Xenon, Xenon Debloated, Emberbium, Prismanium, Polidium, Sodium, VulkanMod
   - Причина: Все эти моды являются самостоятельными движками рендера (форками Sodium или заменами конвейера). Примечание: (Sodium) Chloride, Alloyium и Flerovium НЕ конфликтуют — это аддоны к Embeddium! Установка двух основных движков сразу вызовет краш OpenGL.
   - Решение: Оставьте ТОЛЬКО Embeddium (или Xenon / Emberbium) + совместимые аддоны ((Sodium) Chloride, Alloyium, Flerovium).

2. Катастрофический конфликт с OptiFine (Рендер, culling и FPS):
   - Конфликтующие моды: OptiFine, Embeddium, Emberbium, Xenon, ModernFix, Flywheel, Oculus
   - Причина: OptiFine — закрытый монолит, переписывающий базовые классы рендеринга Minecraft. При совместной установке с современными модами (Embeddium, Flywheel, ModernFix, Oculus) игра гарантированно падает с ошибкой NoSuchMethodError / IncompatibleClassChangeError при запуске.
   - Решение: Полностью удалите OptiFine из папки mods. Вся его функциональность делится на: Embeddium (FPS), Oculus (шейдеры), EBER (сундуки), Embeddium Extras / Chloride (зум и детали).

3. Конфликт Nvidium и шейдеров (Oculus / Iris) (Рендер, culling и FPS):
   - Конфликтующие моды: Nvidium, Oculus, Iris Shaders
   - Причина: Nvidium использует прямой конвейер Mesh Shaders OpenGL, который несовместим с перехватом фреймбуферов шейдер-паков Oculus/Iris. Одновременная активация выключает Nvidium или вызывает черный экран.
   - Решение: Играете БЕЗ шейдеров на NVIDIA RTX — берите Nvidium + Alloyium. Нужны шейдеры — используйте Oculus/Emberlens + Distant Horizons + Alloyium.

4. Конфликт движков освещения (Освещение):
   - Конфликтующие моды: Starlight with Create Fix, Solix, ScalableLux, Lucis (серверное), Radon
   - Причина: Моды полностью заменяют ванильный световой конвейер (LightEngine) на асинхронные структуры данных. Два световых движка одновременно приведут к повреждению чанков света или зависанию генерации мира. (Примечание: LightStar кэширует только клиентские запросы в Embeddium).
   - Решение: На Forge 1.20.1 используйте либо ванильный свет 1.20+ (+ LightStar), либо один движок Solix.

5. Конфликт оптимизаторов листвы (Рендер, culling и FPS):
   - Конфликтующие моды: CullLessLeaves Reforged, OptiLeaves, Leaves Culling, Sodium Leaf Culling (Unofficial), Sodium/Embeddium Leaf Culling
   - Причина: Моды пытаются модифицировать одни и те же шейдеры и модели листьев, вызывая мелькание текстур листвы или черные грани.
   - Решение: Используйте только CullLessLeaves Reforged. Отключите встроенный Leaf Culling в настройках графики.

6. Конфликт сетевых оптимизаторов (Сеть):
   - Конфликтующие моды: Krypton Reno, Krypton Hybrid, Krypton Foxified, AegisNetworking (не ставить вместе с Krypton Hybrid), Krypton
   - Причина: Моды вмешиваются в сетевой конвейер Netty, что при дублировании приводит к потере пакетов и разрыву соединения.
   - Решение: Для чистого Forge 1.20.1 используйте Krypton Reno (для гибрид-серверов Mohist/Arclight — Krypton Hybrid).

7. Конфликт редиректов и перехвата методов (Память и утечки):
   - Конфликтующие моды: Redirected, Redirector [Modern], Jasione
   - Причина: Данные моды заменяют одинаковые байткод-вызовы методов в Java. Старые версии вызывают краши.
   - Решение: Удалите старые Redirected и Redirector. Оставьте только Jasione (или ModernFix).

8. Дубликаты оптимизаторов достижений (Асинхронность, кеш и авторизация):
   - Конфликтующие моды: Fastvancements, Achievements Optimizer, Icterine, Cerulean
   - Причина: Все эти моды патчат один и тот же ванильный класс PlayerAdvancements. Одновременная установка приводит к дублированию событий или крашу при выполнении квестов.
   - Решение: Оставьте только Fastvancements.

9. Дублирование портов Lithium (Radium vs Canary vs Lithium) (Тики, TPS, сущности и ИИ):
   - Конфликтующие моды: Radium Reforged (оригинал), Radium Re-Reforged, Canary, Lithium
   - Причина: Radium Re-Reforged, Radium Reforged, Canary и Fabric Lithium патчат одни и те же классы физики, ИИ и воронок. У версий Radium еще и одинаковый mod id "radium" — игра упадет сразу при старте.
   - Решение: Используйте только один актуальный движок: Radium Re-Reforged (нативно для Forge 1.20.1).

10. Конфликт компенсации тиков (TT20 vs TickAccelerate) (Тики, TPS, сущности и ИИ):
   - Конфликтующие моды: TT20 (TPS Fixer), TickAccelerate
   - Причина: Оба мода масштабируют внутренние таймеры тиков клиентского рендеринга для сглаживания рывков при просевшем TPS сервера. При совместной установке игра начинает дергаться с удвоенной скоростью или сбоит физика передвижения.
   - Решение: Удалите оба для стабильности, либо оставьте максимум один в крайнем случае.

11. Конфликт динамической прорисовки (Чанки и генерация мира):
   - Конфликтующие моды: DynamicRenderDistance, [DRD] Dynamic Render Distance
   - Причина: Два мода динамически меняют render distance в зависимости от текущего FPS. Возникает эффект «резонанса» дальности прорисовки, когда дистанция скачет туда-сюда каждые 2 секунды.
   - Решение: Оставьте только один из них (лучше [DRD] Dynamic Render Distance).

12. Конфликт оптимизаторов сундуков (Рендер, culling и FPS):
   - Конфликтующие моды: Enhanced Block Entities Reloaded, Enhanced Block Entities Reforged (Unofficial), FastChest Revived, Legendary Block Entities, Optimized Block Entities (OBE)
   - Причина: Моды преобразуют анимации сундуков в статические модели блоков. Их одновременная работа приводит к исчезновению текстур сундуков или крашу при открытии двойных сундуков.
   - Решение: Используйте только один из актуальных: Enhanced Block Entities Reloaded (EBER) или Legendary Block Entities.

13. Опасность автоклинеров памяти (System.gc) (Память и утечки):
   - Конфликтующие моды: Simply Server Ram Optimizer [Cleaner], MemGuard, GcGo (серверное), Slime: Heuristic Memory Purger (серверное), RAMization, Furia Memory, Recoleta, Sanitivy, Clean Memory, Memory Cleaning, Better RAM, Memory Optimizer
   - Причина: Принудительные вызовы System.gc() ломают расписание работы JVM-сборщиков G1GC/ZGC, порождая резкие лаги и стоп-кадры каждые пару минут.
   - Решение: Удалите клинеры памяти. Используйте FerriteCore + ModernFix + выделение 6-8 ГБ ОЗУ.

14. Конфликт ModernFix с устаревшим DashLoader (Загрузка игры и ресурспаков):
   - Конфликтующие моды: ModernFix, DashLoader
   - Причина: Оба мода перехватывают загрузку и кэширование JSON-моделей/ресурсов. На Forge через Sinytra Connector DashLoader гарантированно вызывает краш.
   - Решение: Удалите DashLoader и оставьте ModernFix (с опцией Dynamic Resources).
